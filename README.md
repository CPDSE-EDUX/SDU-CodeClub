# SDU Code Club
 
Welcome to the Pharma Code Club at SDU! The Code Club is an informal space for pharmacy students to learn and practise R together, whether you have never written a line of code or want to build on what you already know. Sessions alternate between beginner-friendly and more intermediate topics, with a mix of live coding and time to explore, work through exercises, or bring your own questions.

We share the materials from each session here, including scripts, exercises, and datasets. 
 
The Code Club is run by the [Center for Pharmaceutical Data Science Education (CPDSE)](https://cpdse.dk/).
